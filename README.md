# 📖 Criando um Ebook com IAs

## 🎯 Objetivo do projeto

Criar um ebook utilizando tecnologias de IAs para acelerar o desenvolvimento e compartilhar a experiência no desenvolvimento de um guia completo sobre a evolução da linguagem Java.

## 🛠️ Passos para a construção

Abaixo estão os passos para a construção do ebook

### 1️⃣ Criando um título épico utilizando IA

O primeiro passo foi criar um título para o ebook utilizando o Microsoft Copilot. O título criado foi: 
**Java Bushidō - Do Java 8 ao 25: cortes precisos na evolução**


### 2️⃣ Arte para a capa

Após escolher um título para o ebook, a próxima etapa é criar uma arte para a capa. Aqui foi utilizado o Microsoft Copilot e Gemini Nano Banana 2 para gerar a arte da capa.


### 3️⃣ Conteúdo

Após ter os layouts e a capa, o próximo passo foi criar o conteúdo do ebook utilizando o Microsoft Copilot e o Copilot do PowerPoint para auxiliar na geração e organização do conteúdo.


### 4️⃣ Layout do conteúdo

Depois de montar a capa o próximo passo foi definir o layout do conteúdo para padronizar. Utilizou-se como base o layout do ebook anterior e com o auxílio do Copilot do PowerPoint para melhorias visuais.

### 5️⃣ Revisão e inclusão de conteúdo

Após a elaboração do conteúdo, foi realizada uma revisão detalhada para garantir qualidade e aderência ao projeto.


## 🎨 Ferramentas Utilizadas

- **Microsoft Copilot Chat** - Geração de conteúdo e ideação
- **Gemini Nano Banana 2** - Geração de arte para capa
- **Microsoft PowerPoint com Copilot** - Design e layout do ebook
- **[Carbon](https://carbon.now.sh/)** - Renderização de código com estilo visual
